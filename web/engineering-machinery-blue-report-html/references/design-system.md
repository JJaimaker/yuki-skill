# 工程机械蓝色领导汇报网页规范

## 1. 页面目标

页面服务于董事长、总裁、事业部负责人和传统工业客户。

阅读顺序必须稳定：

1. 先看结论。
2. 再看数字和事实。
3. 最后看动作、负责人和验收方式。

## 2. 颜色

| 角色 | 色值 | 用法 |
|---|---|---|
| 麦肯锡蓝 | `#003A70` | 标题、导航、表头、主结构 |
| 支付宝蓝 | `#1677FF` | 链接、次级强调、交互状态 |
| 深蓝 | `#002B55` | 悬停、深色结构块 |
| 暗三一红 | `#B3212D` | 关键数字、判断、警示、结论 |
| 浅蓝底 | `#EEF5FF` | 方案、辅助信息、次级区域 |
| 页面底色 | `#F4F7FB` | 全页背景 |
| 正文 | `#172231` | 正文和表格内容 |
| 次级文字 | `#5C6B7A` | 注释和说明 |
| 边线 | `#D9E2EC` | 卡片和表格边框 |

蓝色承担 90% 的结构。红色只承担 10% 的决策强调。

## 3. 排版和间距

- 字体：系统中文无衬线。
- 主标题：36 px，600。
- 章节标题：26 px，600。
- 模块标题：18–22 px，500–600。
- 正文：14–17 px，400。
- 行高：1.65–1.75。
- 页面最大宽度：1320 px。
- 左侧目录：260–290 px。
- 章节之间：58–72 px，并用细线分隔。
- 圆角：4–6 px。不要使用大圆角胶囊。
- 阴影：默认禁用。

## 4. 章节模板

每章按下面顺序组织：

1. 章节编号。
2. 结论式标题。
3. 一句章节判断。
4. 架构图、对比表或关键数字。
5. 产品动作或管理动作。
6. 验收口径与风险边界。

不要在章节末增加上一章或下一章按钮。

## 5. 产品说明卡片

产品卡片必须回答三个问题：

| 维度 | 必答内容 |
|---|---|
| 设备类型 | 覆盖哪些作业角色或机型类别 |
| 数据口径 | 使用哪些状态、工时、健康、维护、成本数据 |
| 管理效果 | 数据如何形成任务、验收和复盘 |

链接与说明放在同一张卡片中。

不要只写“8 台矿卡、3 台挖机”。这只是规模，不是方案。

## 6. 文案和标点

- 因果关系用“因为……所以……”或直接说明结果。
- 对比关系用“不是……而是……”。
- 一个主语连续完成多个动作时，不要机械拆句。
- 并列项超过三项时，优先使用表格或流程图。
- 冒号后必须是解释、清单或结论。
- 分号只用于同级并列内容。
- 不使用“赋能、抓手、闭环生态”等空泛词，除非后面给出动作与验收。
- 英文术语首次出现时补中文含义。后文只保留一个固定叫法。

推荐句式：

- `客户的核心问题不是缺少一个功能，而是缺少跨角色的运营闭环。`
- `先用单矿 POC 校验数据和价值，再根据验收结果扩大推广。`
- `规划估算为 350–700 万元，正式立项前仍需按设备接口询价。`

## 7. 事实边界

用明确标签区分：

- `公开事实`：有公开来源。
- `战略判断`：基于事实做出的推断。
- `试点假设`：等待 POC 验证。
- `规划估算`：用于预算讨论，不是正式报价。
- `待报价`：必须向供应商或内部采购确认。

## 8. 成本表

成本表至少包含：

| 模块 | 当前状态 | AI 改造后 | 首年成本 | 后续年费 | 前置或后置 |
|---|---|---|---:|---:|---|
| 感知 | 现有数据源 | 新增采集与机端推理 | 区间 | 区间 | 前置 |
| 计划 | 人工排程 | 仿真与优化 | 区间 | 区间 | 并行 |
| 执行 | 人工操作 | 助手或无人化 | 区间 | 区间 | 后置可选 |
| 维修 | 人工检索 | 多模态诊断 | 区间 | 区间 | 并行 |
| 复盘 | 周期复盘 | 班次级洞察 | 区间 | 区间 | 持续 |

写清设备规模、矿区条件、复用范围和排除项。

## 9. 交互和响应式

- 桌面端：左侧目录固定，正文连续滚动。
- 移动端：目录变为顶部横向滚动条。
- 目录点击后使用原生锚点滚动。
- Scrollspy 只更新高亮。
- 不切换章节显示状态。
- SVG 设置 `max-width:100%`。
- 宽表格使用内部横向滚动。
- 页面本身不得横向溢出。

## 10. Netlify 包结构

```text
project/
└── dist/
    ├── index.html
    └── _redirects
```

`_redirects` 内容：

```text
/* /index.html 200
```

页面默认自包含。不要依赖本机绝对路径。

## 11. 交付检查

- 目录、章节和锚点逐项对齐。
- 连续滚动可读。
- 关键数字使用暗红色。
- 来源和假设明确分开。
- 产品卡片说明“类型—数据—效果”。
- 成本有范围、口径和排除项。
- 1280 px 和 390 px 两种视口无页面溢出。
- 浏览器控制台无错误。
- 本地 HTTP 访问通过。
